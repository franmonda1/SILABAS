# 🎈 Aventuras Silábicas - Conciencia Silábica

Aplicación interactiva diseñada especialmente para **pizarras digitales interactivas (PDI)**, **tablets** y ordenadores, orientada a que los alumnos de Educación Infantil y primeros cursos de Primaria desarrollen y refuercen la **conciencia silábica**.

---

## 🚀 Cómo usar la aplicación

1. **Abrir el juego:**
   - Haz doble clic sobre el archivo `index.html` para abrirlo directamente en cualquier navegador moderno (Google Chrome, Microsoft Edge, Safari o Firefox).
   - No requiere conexión a internet ni instalación de servidores (funciona 100% offline).

2. **Añadir la fuente escolar (`Escolar_N.TTF`):**
   - El código ya está programado y enlazado con `@font-face` para la fuente `Escolar_N.TTF`.
   - Simplemente copia y pega tu archivo `Escolar_N.TTF` dentro de esta misma carpeta (`C:\Users\USUARIO\.gemini\antigravity\scratch\conciencia-silabica`). El navegador la detectará y aplicará de forma automática en todos los textos, sílabas y ranuras.
   - Mientras tanto, cuenta con una fuente de trazo infantil y redondeada como respaldo.

- **¡Modo Desafío Aleatorio! (⚡ 🎯):**
  - Mazo gigante que toma de forma aleatoria palabras sorpresa de **todas las 26 letras y combinaciones**, sin repetirse.
  - El alumno no sabe qué consonante vendrá a continuación, poniendo a prueba su agilidad auditiva y conciencia silábica global.
  - Permite jugar por rondas consecutivas de 10 palabras o avanzar a través de todo el banco de 520 palabras.
- **Banco ampliado de palabras:** Exactamente **20 palabras por cada grupo consonántico (520 palabras en total)** con división silábica fonéticamente rigurosa (sin letras sueltas ni omisiones) e ilustraciones claras y reconocibles para niños de infantil y primaria.
- **Botón de sonido en cada palabra (🔊):** Pronuncia la palabra en español claro y pausado con la API de síntesis de voz del navegador.
- **Alternador de Mayúsculas / Minúsculas (aA):** Permite cambiar con un solo clic o toque toda la interfaz entre texto en mayúscula y minúscula, facilitando la adaptación al nivel lectoescritor de los alumnos.
- **Sonidos interactivos y vibración:**
  - Acordes alegres de éxito con confeti festivo al acertar.
  - Efecto de sonido suave de error, animación de temblor (*shake*) y vibración háptica en tablets compatibles.
- **Botón de Pantalla Completa (⛶):** Ocupa toda la pizarra digital sin barras de herramientas molestas.
- **Botón de Inicio (🏠):** Para cambiar de consonante en cualquier momento.
